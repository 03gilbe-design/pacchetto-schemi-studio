3) Indirizzamento associativo a gruppi (set-associative)

CACHE · Fig. 8.18

Idea

Diretto + Associativo insieme: le posizioni di cache sono riunite in GRUPPI. Ogni blocco di memoria è legato a un solo gruppo (come nel diretto), ma dentro il gruppo può andare in una qualsiasi posizione (come nell'associativo).

Perché

  • Meno conflitti del diretto
  • Costo circuitale minore dell'associativo

Relazione blocco → posizione

Blocco → gruppo = funzione
Blocco → posizione = NON funzione (il gruppo ha >1 posizione: si sceglie)

Esempio (Fig. 8.18)

  • 64 gruppi × 2 posizioni = 128 posizioni
  • Memoria: 4.096 blocchi
  • Gruppo 0 ← blocchi 0, 64, 128 … 4.032 → posizione 0 o 1
  • Gruppo 1 ← blocchi 1, 65, 129 … 4.033 → posizione 2 o 3
  • Ogni gruppo ← 4.096/64 = 64 blocchi

Come si cerca il blocco

  1. Campo gruppo → individuo il gruppo
  2. Confronto l'etichetta con quelle delle posizioni del gruppo (ricerca associativa)
  3. Coincidenza = copia trovata (HIT)
    Nessuna = blocco non in cache (MISS)

Mappa: memoria centrale ⇄ cache a gruppi

Indirizzo di memoria

6 bit ETICHETTA
6 bit GRUPPO
4 bit OFFSET
quale blocco del gruppo
quale gruppo (2⁶=64)
parola nel blocco
  • Etichetta = n − spiazzamento − gruppo = 16 − 4 − 6 = 6 bit (64 blocchi per gruppo)
  • Gruppo = ⌈log₂(# gruppi)⌉ = 6 bit  ·  Spiazz. = ⌈log₂ b⌉ = 4 bit

Formule (legenda)

  • # blocchi = 2n/b
  • # posizioni = 2m/b
  • # gruppi = # posizioni / v
  • v = posizioni per gruppo (= # vie)
